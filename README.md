# Pixels to Punk Themes for Zed

**Beautiful color themes for your code editor.**

Think of themes like choosing the "look and feel" of your code editor — like picking a color scheme or background for your phone. These 50 themes change the colors you see while writing code, making it more fun and easier on your eyes.

## What Themes Are Included?

50 themes organized by style:

- **Dark Themes** - Better for coding at night
- **Light Themes** - Better for daytime work
- **Low-Glare Themes** - Easier on your eyes (especially with glasses)
- **Fun & Colorful** - Neon, arcade, anime, and cyberpunk inspired
- **Calm & Neutral** - Soft colors, less intense

You'll find themes named things like "Cyber Dark," "Sakura Sprint," "Arcade Raincoat," "Tokyo Fog Cutter," and many more.

### Install Now (Clone from GitHub)

Want to use these themes right now? Clone the repo to your extensions folder and Zed will automatically recognize it. 

**Step 1: Open Terminal**
Copy and paste the command below into your terminal:

**Mac & Linux:**
```bash
git clone https://github.com/ryemyster/zed-ide-fptp-themes ~/.config/zed/extensions/fptp-themes
```

**Windows (PowerShell):**
```powershell
git clone https://github.com/ryemyster/zed-ide-fptp-themes $env:APPDATA\Zed\extensions\fptp-themes
```

**Step 2: Restart Zed**
- Close Zed completely
- Reopen Zed
- The extension will automatically load

**Step 3: Pick Your Theme**
- Open Settings: `Cmd + ,` (Mac) or `Ctrl + ,` (Windows/Linux)
- Search for `theme`
- Select any theme starting with "Pixels to Punk"
- Your colors change instantly! 🎨
