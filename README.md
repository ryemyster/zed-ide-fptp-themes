# Pixels to Punk Themes for Zed

A collection of 50 vibrant, cyberpunk and anime-inspired color themes for the Zed editor.

## Themes Included

All themes from the original [Pixels to Punk VSCode Themes](https://github.com/ryemyster/fptp-vscode-themes) have been converted for Zed, including:

- **Cyber Dark / Light** - The flagship cyberpunk themes
- **For Those with Glasses** - Lower-glare variants for reduced eye strain
- **Soft Focus** - Day and night variants with muted colors
- **High Contrast** - Enhanced contrast for accessibility
- **Anime-inspired** - Harajuku, Shibuya, Shinjuku, Tokyo, Kyoto themed palettes
- **Arcade/Gaming** - Retro arcade, CRT, Game Dev aesthetics
- **Nature** - Sakura, Matcha, Onsen themes
- **Experimental** - Neon, Glow, Riot, and other bold variations

## Installation

Install this extension directly from the Zed extensions marketplace:

1. Open Zed settings (Cmd+,)
2. Go to Extensions
3. Search for "Pixels to Punk"
4. Click Install

Or clone this repo and link it:

```bash
git clone https://github.com/ryemyster/zed-themes ~/.config/zed/extensions/fptp-themes
```

## Using a Theme

1. Open Zed settings (Cmd+,)
2. Search for "theme"
3. Select your preferred Pixels to Punk theme

## Development

To rebuild the themes after modifying the conversion script:

```bash
npm run convert
```

This reads from the VSCode themes source and regenerates all Zed theme files.
